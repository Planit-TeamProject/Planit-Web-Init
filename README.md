# Planit Frontend

## 처음 실행하는 법
```
npm install
npm run dev
```
브라우저에서 http://localhost:5173 열면 초기화면이 보여요.

## 폴더 구조
```
src/
  App.jsx          라우팅 설정 (/  /login  /signup)
  pages/
    LandingPage.jsx   초기화면 (완성)
    LoginPage.jsx      로그인 (placeholder, 인증 담당자가 교체)
    SignupPage.jsx     회원가입 (placeholder, 인증 담당자가 교체)
```

각자 화면은 `src/pages/` 아래에 자기 페이지 파일 추가하고, `App.jsx`에 라우트 한 줄만 추가하면 됩니다.
